Tutorial

Unofficial local tool: turn Splunk’s documentation icon sheet into draw.io libraries on your machine. Not a Splunk product.

This repo does not ship the icons.

1. Get the icon sheet

The current file is the Transparent PNG on Splunk’s Draw a diagram of your deployment page. This workbench saves it as source/Splunk_Documentation_Icons_August2018.png.

2. Build libraries

Python 3.10+ and uv, from the repo root:

uv sync
uv run python run_pipeline.py all
uv run python app.py

run_pipeline.py all also downloads the PNG into source/ if it is missing. Titles come from canonical_titles.json.

3. Import into draw.io

  1. Open diagrams.net or the desktop app.
  2. File → Open Library From → Device (not Import).
  3. Choose a generated .xml from local dist/ (or the links below after a build). Draw.io does not import .drawiolib.
  4. Enable the library in the left sidebar if needed (+ / More Shapes).
LibraryUse when
Splunk-Icons-configurable.xml Native stencils — Style panel fill/line, hostname/IP via Edit Data.
Splunk-Icons-adaptive.xml Theme-aware picture icons for light and dark canvases.
Splunk-Icons-color.xml Full-color PNG pictures on light backgrounds.
Splunk-Icons-dark.xml Inverted PNG pictures on dark backgrounds.
Splunk-Connectors.xml Connector presets.

On a configurable shape: Fill is the icon color. Line color is an optional outline. Edit → Edit Data (Ctrl+M / Cmd+M) stores hostname, ip, and notes.

This workbench

Labels — rename titles; Save to catalog writes canonical_titles.json. Custom crops — only if the grid missed an icon. After either, click Rebuild XML.
