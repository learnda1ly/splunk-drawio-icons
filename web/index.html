Tutorial

Unofficial local tooling: download Splunk’s documentation icon sheet, build draw.io libraries on your machine, and use them to diagram a Splunk deployment. This is not a Splunk product and is not endorsed by Splunk.

This repo does not ship the icons. Put the PNG in source/, run the pipeline so files appear under local dist/, then import those .xml files into draw.io.

This workbench

One local app, three stages:

  1. Tutorial — this page.
  2. Labels — search and fix icon titles, then rebuild libraries.
  3. Custom crops — draw a box on the source sheet for icons the grid missed.

OCR and full rebuilds still run from the CLI (below). You do not need Jupyter.

Import into draw.io

  1. Open diagrams.net or the desktop app.
  2. File → Open Library From → Device (not Import — that opens diagrams).
  3. Choose a generated .xml from your local dist/ (or the links below after you have built). Draw.io does not import .drawiolib.
  4. Enable the library in the left sidebar if needed (+ / More Shapes).
LibraryUse when
Splunk-Icons-configurable.xml Native stencils — Style panel fill/line, hostname/IP via Edit Data. Closest to Visio.
Splunk-Icons-adaptive.xml Theme-aware picture icons for light and dark canvases (not Style-panel fill).
Splunk-Icons-color.xml Full-color PNG pictures on light backgrounds.
Splunk-Icons-dark.xml Inverted PNG pictures on dark backgrounds.
Splunk-Connectors.xml Splunk-style connector presets.

On a configurable shape: Fill is the icon color (black in light mode, white in dark). Line color is an optional outline. Edit → Edit Data (Ctrl+M / Cmd+M) stores hostname, ip, and notes on that instance. Hover for N/E/S/W connection points.

Draw.io cannot recolor PNG pixels, keep official multi-color art and a single Fill picker, or provide Visio ShapeSheet formulas. Edit Data plus %placeholder% labels is the equivalent.

Setup (rebuild from source)

Python 3.10+ and uv, then from the repo root:

uv sync
uv run python app.py         # this workbench → http://127.0.0.1:8765

Install Tesseract OCR only if you re-run OCR. Download Splunk’s sheet from Draw a diagram of your deployment and save it as source/Splunk_Documentation_Icons_August2018.png (gitignored). Then run uv run python run_pipeline.py all so local dist/ libraries exist.

CLI pipeline

uv run python run_pipeline.py all      # crops → OCR → labels → libraries
uv run python run_pipeline.py crops
uv run python run_pipeline.py ocr
uv run python run_pipeline.py labels
uv run python run_pipeline.py build    # same as Rebuild in Labels / Custom crops

After you save titles or custom crops here, click Rebuild XML so dist/Splunk-Icons-*.xml updates.
